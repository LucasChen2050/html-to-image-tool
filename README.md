# HTML 知识卡片转图片工具

一个简单易用的在线工具，可以将 HTML 代码转换为高清图片。

## 功能特点

- 📝 实时预览 HTML 效果
- 📥 下载高清图片（支持 1x-5x 质量）
- 🎨 美观的渐变色界面
- 📱 响应式设计，支持移动端
- 🚀 纯前端实现，无需后端

## 使用方法

1. 访问网站
2. 在左侧输入框粘贴 HTML 代码
3. 右侧实时预览效果
4. 调整图片质量
5. 点击下载按钮保存图片

## 在线访问

[点击访问工具](https://你的用户名.github.io/仓库名/)

## 本地运行

直接用浏览器打开 `html-to-image.html` 文件即可。

## 技术栈

- HTML5
- CSS3
- JavaScript
- html2canvas
